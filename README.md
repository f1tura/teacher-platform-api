# Teacher Platform API

Backend API для Mini-LMS / Teacher Platform на Go.  
Проект реализует базовую учебную платформу с ролями **teacher**, **student** и **admin**, где преподаватель может создавать курсы, уроки и задания, добавлять студентов, отмечать посещаемость и проверять решения, а студент — отправлять домашние работы и смотреть свой прогресс.

## Возможности

### Авторизация и роли
- регистрация пользователя
- логин по email/password
- JWT-аутентификация
- middleware для проверки токена
- middleware для проверки ролей
- роли: `admin`, `teacher`, `student`

### Пользователи
- создание пользователя
- просмотр списка пользователей
- просмотр пользователя по id
- обновление пользователя
- удаление пользователя

### Курсы
- создание курса
- просмотр списка курсов
- просмотр курса по id
- обновление курса
- удаление курса
- проверка владения курсом: преподаватель может изменять только свои курсы

### Студенты курса
- добавление студента в курс
- получение списка студентов курса
- удаление студента из курса

### Уроки
- создание урока в курсе
- список уроков курса
- просмотр урока по id
- обновление урока
- удаление урока

### Задания
- создание задания в уроке
- список заданий урока
- просмотр задания по id
- обновление задания
- удаление задания

### Решения студентов
- студент отправляет решение по заданию
- студент обновляет своё решение до дедлайна
- студент удаляет своё решение до дедлайна
- преподаватель просматривает решения
- преподаватель проверяет решение, выставляет балл и статус

### Прогресс
- студент может смотреть свой прогресс
- преподаватель может смотреть прогресс своих студентов
- агрегаты:
  - количество заданий
  - количество отправленных решений
  - количество проверенных решений
  - средний балл
  - completion rate

### Посещаемость
- преподаватель отмечает посещаемость студента на уроке
- просмотр посещаемости урока
- обновление записи посещаемости

## Стек технологий

- **Go**
- **Gin**
- **PostgreSQL**
- **PGX**
- **Docker / Docker Compose**
- **Goose** для миграций
- **JWT**
- **bcrypt**
- **Swagger (swaggo)**

## Архитектура проекта

Проект организован по слоям:

- `handlers` — HTTP-слой, роуты и работа с запросами/ответами
- `dto` — входные структуры для API
- `models` — основные сущности
- `repository` — работа с PostgreSQL
- `auth` — JWT и хэширование паролей
- `middleware` — аутентификация и роли
- `config` — загрузка конфигурации
- `database` — подключение к БД
- `migrations` — SQL-миграции
- `docs` — Swagger-документация
